# berry-systems.de

Webauftritt von Berry Systems: Startseite, Nagelfest-Produktseite, Impressum und Datenschutzerklärungen.
Statische Seiten, bereitgestellt über GitHub Pages (Domain in `CNAME`).

- Keine externen Einbindungen, keine Cookies, kein Tracking. Animationen respektieren „Bewegung reduzieren“.
- Datenschutzerklärung der App Nagelfest (für die Play Console): `nagelfest/datenschutz.html`
- Schriften: Instrument Serif und Barlow, SIL Open Font License 1.1 (`fonts/*OFL.txt`)
